# Craft Cut Coach

**Craft Cut Coach (for Cricut® machines)**: a free plugin for Cursor and Grok Bot that helps crafters fix failed cuts and get iron-on and heat-press settings right, one calm step at a time.

> Unofficial. Not affiliated with, endorsed by, or sponsored by Cricut, Inc. Cricut® is a trademark of Cricut, Inc.

## What's included
| Skill | What it does |
|---|---|
| `getting-started` | First chat: welcome, learn the machine and experience level, start a first fix |
| `fix-failed-cut` | Decision tree and 15 symptom playbooks (tearing, not cutting through, mat issues, Print Then Cut, weeding, iron-on, grinding, connection) with public sources |
| `heat-press-starting-points` | Starting-point settings by press and iron-on type, plus no-stick and after-wash fixes |

Everything in the plugin is free and fully usable. Nothing is locked.

## Install
- **Marketplace:** once listed, install "Craft Cut Coach" from the plugin marketplace.
- **Local test:** clone this repo and follow Cursor's plugin docs for loading a local plugin: https://cursor.com/docs/plugins

## Usage
Ask things like "My vinyl letters tore on my Explore Air 2" or "What temperature for glitter iron-on with an EasyPress 2?"

## Important
- Settings and fixes are starting points from public sources, not tested by us. Always cut a 1-inch test square or press a hidden test spot first.
- Not Cricut support. For hardware problems, contact Cricut Member Care.
